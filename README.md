# Notificator — Telegram-бот «Трекер целей»

Бот помогает выработать привычку выполнять дела каждый день. Вы составляете
список дел, отмечаете выполненные, а бот сам напоминает о невыполненных и
присылает статистику.

## Что умеет

- Ведёт список ежедневных дел (добавление, удаление, отметка о выполнении).
- Утром присылает итог вчерашнего дня: «выполнено X из Y».
- Днём напоминает о невыполненных делах и добавляет мотивационную цитату.
- По понедельникам присылает отчёт и метрику продуктивности за неделю.
- Время уведомлений считается по часовому поясу пользователя.

Команды: `/start`, `/menu`, `/add`, `/today`, `/remove`, `/reminders`, `/week`, `/cancel`.

## Стек

Java 21, Spring Boot, Gradle, H2 (файловая база), Telegram Bots (long polling).

## Подготовка

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Токен передаётся **только через переменную окружения** `TELEGRAM_BOT_TOKEN`
   (в код и в git он не попадает).

## Запуск локально

Нужен JDK 21.

```bash
# Linux / macOS
export TELEGRAM_BOT_TOKEN=ваш_токен
./gradlew bootRun
```

```powershell
# Windows (PowerShell)
$env:TELEGRAM_BOT_TOKEN = "ваш_токен"
.\gradlew.bat bootRun
```

Данные хранятся в `./data/tracker.mv.db`, логи — в `./logs/notificator.log`.

## Запуск в Docker (для сервера)

```bash
cp .env.example .env        # впишите токен в .env
docker compose up -d --build
```

Контейнер перезапускается автоматически, данные и логи лежат в томах Docker
и переживают обновление образа. Остановить: `docker compose stop`.

## Тесты

```bash
./gradlew test
```

## Настройки

Время уведомлений и прочие параметры — в `src/main/resources/application.yaml`
(секция `notifications`). Подробное описание задумки — в [SPEC.md](SPEC.md).
